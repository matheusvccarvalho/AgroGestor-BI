# AgroGestor BI

Plataforma de demonstração para gestão agrícola e acompanhamento de indicadores.

## Tecnologias planejadas
- Java e Spring Boot: backend
- MySQL: banco de dados
- HTML, CSS e JavaScript: interface
- Power BI: análises complementares em etapa futura

## Indicadores demonstrativos
- Área plantada
- Produtividade estimada
- Custo por hectare
- Produção estimada

**Atenção:** os números exibidos na interface são fictícios e servem apenas para demonstração.

## Estrutura
- `backend/`: aplicação Java
- `frontend/`: interface web
- `database/`: scripts SQL
